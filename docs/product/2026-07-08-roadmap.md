# RapperRank Roadmap

## Roadmap Goal

这份路线图的目标不是把功能塞满，而是用三个版本回答三个问题:

1. 用户为什么要留下评分
2. 用户为什么要回来
3. 用户为什么要在这里和别人发生关系

产品阶段判断:

- 当前已具备图鉴和评分基础
- 主要短板在回访和社区场景
- 所以路线应该从 `个人回报` 走向 `公共比较`，最后再走向 `社区沉淀`

## Versioning Principle

### v1

验证“评分不是一次性动作，而是会变成我的档案”。

### v1.5

验证“我的判断可以和社区形成张力，进而驱动表达和回访”。

### v2

验证“RapperRank 可以从图鉴和评分平台长成真正的互动社区”。

## v1: Build The Personal Loop

### Version Goal

让用户第一次明显感受到:

- 我的评分被记住了
- 我的口味在形成
- 我再评几个会得到更多反馈

### Core Problem

现在用户可以评分，但评分之后缺少明确回报。收藏和记录存在，但还没有形成“个人档案”的产品感。

### Main Features

#### 1. 我的评分档案

- 显示总评分数、最近评分、喜爱度分布
- 输出个人口味标签
- 输出维度倾向，比如更重 Flow、Lyrics 还是 Melody、Stage
- 给出“你更偏哪类 Rapper”的阶段性判断

#### 2. 评分进度反馈

- 评分 3 人、10 人、20 人时给出不同层级反馈
- 让用户知道“继续评会发生什么”

#### 3. 个人中心升级

- 把现有收藏和评分记录组织成更强的个人资产页
- 从“记录列表”升级为“我的说唱判断档案”

### Success Metrics

- 新用户 3 次评分达成率
- 用户查看档案页占比
- 用户首周人均评分数
- 7 日回访率

### Out Of Scope

- 评论区
- 关注关系
- 复杂消息系统
- 商业化付费功能

## v1.5: Build The Public Loop

### Version Goal

让用户明显感受到:

- 社区不是背景板
- 我的判断和别人的判断会形成分歧与对照
- 我有理由回来看看变化

### Core Problem

当前社区页更像展示页，而不是表达场。需要一个“有话题密度”的公共面板，但不要过早做重社交。

### Main Features

#### 1. 争议榜

- 最分裂 Rapper
- 最高共识 Rapper
- 喜爱度高但综合分分裂的 Rapper
- 最近波动明显的 Rapper

#### 2. 今日三连评

- 每天给用户一个轻量挑战
- 主题可来自厂牌、城市、风格或“相近但容易分裂”的 3 个 Rapper
- 完成后输出一句总结性反馈

#### 3. 社区对比视图

- 我的评分 vs 社区均分
- 我在哪些维度上明显高于或低于社区
- 哪些 Rapper 是“我最不随大流”的判断

### Success Metrics

- 社区页点击深度
- 争议榜进入详情页比例
- 今日三连评完成率
- 社区功能带来的新增评分数

### Out Of Scope

- 长评论
- 私信
- 复杂点赞体系
- 大规模内容运营工具

## v2: Build The Community Identity Layer

### Version Goal

让用户愿意把 RapperRank 当成自己的公开表达空间，而不是只当作评分工具。

### Core Problem

如果没有身份层和公共内容层，社区会一直停留在功能层。v2 才应该开始把“人”和“内容”真正连起来。

### Main Features

#### 1. 公开个人主页

- 对外展示个人评分风格
- 展示代表性判断
- 展示最爱 Rapper、最不随大流 Rapper、口味标签

#### 2. 主题专题和厂牌赛

- 围绕厂牌、城市、时期、风格做周期性专题
- 让评分和图鉴页面被公共话题重新激活

#### 3. 年度审美报告

- 年内评分变化
- 口味迁移
- 最爱的厂牌和风格
- 与社区的重合与偏离

#### 4. 轻关系系统

- 关注相似口味用户
- 看见值得参考的公开评分档案

### Success Metrics

- 公开主页创建率
- 专题参与率
- 社区二次传播率
- 30 日回访率

### Out Of Scope

- 泛娱乐化内容流
- 过早的视频化表达
- 复杂即时互动

## Recommended Sequence

最推荐的执行顺序:

1. 先做“我的评分档案”
2. 再做“争议榜”
3. 再做“今日三连评”
4. 然后再做公开主页和专题

原因很直接:

- 没有个人档案，用户没有沉淀
- 没有公共分歧，社区没有张力
- 没有轻挑战，回访没有节奏
- 这三件事成立后，再做公开身份才有意义

## What To Keep Removing

未来每一版都要持续克制下面几件事:

- 不为了“像社区”而先上重评论区
- 不为了“像游戏”而先上勋章积分
- 不为了“像媒体”而先做很多资讯内容
- 不为了“像工具”而把页面做得过于冷静

RapperRank 的正确节奏应该是:

`图鉴气质 -> 评分表达 -> 个人档案 -> 社区分歧 -> 公开身份`

## Build Notes

结合当前项目基础，路线图有几个现实优势:

- 评分系统已存在
- 收藏和个人中心已存在
- 社区榜单页已存在
- 厂牌页已存在
- 随机探索和详情页体验已存在

所以当前不是从零开始，而是要把已有页面从“可用”收紧成“有回访逻辑”。
